# Contributing

Issues, bug reports and pull requests are welcome.

- **Bugs and feature requests:** open an issue here, or use
  [backup-buddies-feedback](https://github.com/mspencerl87/backup-buddies-feedback/issues)
  if you'd rather not dig into code.
- **Security problems:** please don't open a public issue. Email
  support@filegarden.net with the details and we'll reply before anything
  is disclosed.
- **Pull requests:** keep them focused on one change, and say what you saw
  and how you tested it. `docs/` has the API reference (`API.md`) and how
  everything runs (`OPERATIONS.md`).

## Sign off your commits

Every commit needs a `Signed-off-by:` line, which `git commit -s` adds. It
means you agree to the [Developer Certificate of Origin](https://developercertificate.org/):
that you wrote the change (or otherwise have the right to submit it) and
that it can be distributed under this project's license.
